# B1 — Communes (maires, conseils municipaux)

**Status:** scope stub (foundation of 3 Nov 2026). Milestones to be agreed with JM before any feature work (plan mode first).

## Mission
Budgets des 34 communes (OFGL, DGFiP), conseil municipal (RNE), site de la mairie (audit + avis des visiteurs), historique des maires. MVP2 en production (vwapepla.org).

## Owned paths (only B1 edits them)
- Route: `src/app/communes/**`
- Components: `src/components/communes/**` · domain logic and reads: `src/lib/communes/**`
- Strings: `messages/fr/communes.json`, `messages/gcf/communes.json` (Kréyòl only where agreed)
- Scripts: `scripts/communes/**` (`sources.py`, `tables.py`, build scripts) · data: `data/communes/**`, `data/raw/communes/` (gitignored)
- Database: tables prefixed `com_`, migrations `supabase/migrations/<timestamp>_com_<topic>.sql`

Shared files (card shell, core tables, `common.json`, layout, config, CI…) change only through a separate PR to `dev`.

## Data sources (from docs/BRIEF.md §4)
OFGL comptes des communes, DGFiP balances, AFD Observatoire, RNE, résultats des municipales, annuaire Service-Public, rapports CRC Antilles-Guyane. Every source is added to `scripts/communes/sources.py` and downloaded with
`python -I scripts/core/download_sources.py --domain communes` (manifest with licence, date, sha256).

## Data model
People and mandates go in the core tables (`institutions`, `bodies`, `seats`, `persons`, `mandates`; `acquired` =
direct_election / indirect_election / appointment). Domain facts go in `com_*` tables, each row with a `source_id`.

## Card
Built from `src/components/card/Card.tsx` (header with portrait and credit, sourced fact blocks, missing information,
caveats, right of reply, opinion block kept apart). Neutral: no score, no ranking.

## First milestones
Promesses 2026–2032 (phase 2), budgets prévisionnels, carte, « investi pour votre population » (EPCI).
