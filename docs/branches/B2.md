# B2 — Parlementaires (députés, sénateurs)

**Status:** scope stub (foundation of 3 Nov 2026). Milestones to be agreed with JM before any feature work (plan mode first).

## Mission
Fiches des députés et sénateurs de Martinique : présence, votes, amendements, propositions de loi, questions écrites, par législature.

## Owned paths (only B2 edits them)
- Route: `src/app/parlementaires/**`
- Components: `src/components/parlement/**` · domain logic and reads: `src/lib/parlement/**`
- Strings: `messages/fr/parlement.json`, `messages/gcf/parlement.json` (Kréyòl only where agreed)
- Scripts: `scripts/parlement/**` (`sources.py`, `tables.py`, build scripts) · data: `data/parlement/**`, `data/raw/parlement/` (gitignored)
- Database: tables prefixed `parl_`, migrations `supabase/migrations/<timestamp>_parl_<topic>.sql`

Shared files (card shell, core tables, `common.json`, layout, config, CI…) change only through a separate PR to `dev`.

## Data sources (from docs/BRIEF.md §4)
Assemblée nationale et Sénat (open data), NosDéputés / NosSénateurs (Regards Citoyens), RNE, HATVP. Every source is added to `scripts/parlement/sources.py` and downloaded with
`python -I scripts/core/download_sources.py --domain parlement` (manifest with licence, date, sha256).

## Data model
People and mandates go in the core tables (`institutions`, `bodies`, `seats`, `persons`, `mandates`; `acquired` =
direct_election / indirect_election / appointment). Domain facts go in `parl_*` tables, each row with a `source_id`.

## Card
Built from `src/components/card/Card.tsx` (header with portrait and credit, sourced fact blocks, missing information,
caveats, right of reply, opinion block kept apart). Neutral: no score, no ranking.
