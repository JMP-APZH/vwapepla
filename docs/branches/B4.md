# B4 — Préfet de Martinique (nommé)

**Status:** see [Status](#status-10-nov-2026) below (updated 10 Nov 2026). Card live at `/prefet` since release #71 (9 Nov 2026).

## Mission
Fiche d'un responsable **nommé** (pas de programme, pas de « promesses ») : actions de l'État, arrêtés, gestion de crise, financements de l'État.

## Owned paths (only B4 edits them)
- Route: `src/app/prefet/**`
- Components: `src/components/prefet/**` · domain logic and reads: `src/lib/prefet/**`
- Strings: `messages/fr/prefet.json`, `messages/gcf/prefet.json` (Kréyòl only where agreed)
- Scripts: `scripts/prefet/**` (`sources.py`, `tables.py`, build scripts) · data: `data/prefet/**`, `data/raw/prefet/` (gitignored)
- Database: tables prefixed `pref_`, migrations `supabase/migrations/<timestamp>_pref_<topic>.sql`

Shared files (card shell, core tables, `common.json`, layout, config, CI…) change only through a separate PR to `dev`.

## Data sources (from docs/BRIEF.md §4)
Recueil des actes administratifs de la préfecture, données de l'État (dotations, financements), communiqués officiels. Every source is added to `scripts/prefet/sources.py` and downloaded with
`python -I scripts/core/download_sources.py --domain prefet` (manifest with licence, date, sha256).

## Data model
People and mandates go in the core tables (`institutions`, `bodies`, `seats`, `persons`, `mandates`; `acquired` =
direct_election / indirect_election / appointment). Domain facts go in `pref_*` tables, each row with a `source_id`.

## Card
Built from `src/components/card/Card.tsx` (header with portrait and credit, sourced fact blocks, missing information,
caveats, right of reply, opinion block kept apart). Neutral: no score, no ranking.
