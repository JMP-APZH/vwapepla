## Mission
Fiches de la Collectivité Territoriale de Martinique : budget, décisions sur l'octroi de mer, grands programmes ; élus de l'Assemblée et du Conseil exécutif.

## Owned paths (only B3 edits them)
- Route: `src/app/ctm/**`
- Components: `src/components/ctm/**` · domain logic and reads: `src/lib/ctm/**`
- Strings: `messages/fr/ctm.json`, `messages/gcf/ctm.json` (Kréyòl only where agreed)
- Scripts: `scripts/ctm/**` (`sources.py`, `tables.py`, build scripts) · data: `data/ctm/**`, `data/raw/ctm/` (gitignored)
- Database: tables prefixed `ctm_`, migrations `supabase/migrations/<timestamp>_ctm_<topic>.sql`

Shared files (card shell, core tables, `common.json`, layout, config, CI…) change only through a separate PR to `dev`.

## Data sources (from docs/BRIEF.md §4)
Comptes de la CTM (OFGL / DGFiP), délibérations, RNE, rapports CRC. Every source is added to `scripts/ctm/sources.py` and downloaded with
`python -I scripts/core/download_sources.py --domain ctm` (manifest with licence, date, sha256).

## Data model
People and mandates go in the core tables (`institutions`, `bodies`, `seats`, `persons`, `mandates`; `acquired` =
direct_election / indirect_election / appointment). Domain facts go in `ctm_*` tables, each row with a `source_id`.

## Card
Built from `src/components/card/Card.tsx` (header with portrait and credit, sourced fact blocks, missing information,
caveats, right of reply, opinion block kept apart). Neutral: no score, no ranking.
